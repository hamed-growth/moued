# Technical Risk Register

The release column refers to public production. The API column distinguishes starting a local read-only API from shipping an affected operation. Severity reflects the observed impact and the affected workflow.

| Severity and domain | Evidence and impact | Product decision | Future action | Blocks public release | Blocks API development |
| --- | --- | --- | --- | --- | --- |
| Critical · Deployment configuration | Default settings use DEBUG, development secret configuration, empty ALLOWED_HOSTS and console mail. check --deploy reported mail.E001 and W004, W008, W009, W012, W016, W018 and W020. Public requests could expose debug details and lack intended transport/cookie controls. | No, deployment design required | Configure environment-backed secrets, explicit hosts, TLS/proxy, secure cookies, HSTS after TLS validation, operational mail and monitored static/media delivery. Rerun checks on production settings. | Yes | No for local design |
| High · Admin competition authorization | Staff with view_competition alone sent an Admin finalization POST and changed active to finished in a synthetic database. CompetitionAdmin action lacks an explicit change permission. Financial payout follows the same service path when qualifying rows exist. | Define delegated scope if needed | Require explicit action and object scope. Audit activation and fulfillment actions for equivalent behavior and add negative authorization tests. Only finalization was reproduced here. | Yes | Blocks privileged mutation exposure |
| High · Account login redirect | Successful login with next=https://example.invalid/ returned 302 to that external target. An attacker can use the trusted origin as a phishing redirect. | No | Validate redirect hosts and schemes and test hostile next values. Also review dashboard actions that use the HTTP Referer as redirect input. | Yes | Blocks reusing this login flow publicly |
| High · Competition late answers | Existing independent-connection test records an answer after finalization, after it passed initial checks.
